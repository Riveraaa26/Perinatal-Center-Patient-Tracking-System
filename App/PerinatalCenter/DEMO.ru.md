# Демонстрация на 4–6 минут

Начните со свежей тестовой БД, выполните шаги из README.ru.md. Здесь используются отделения и палаты из скрипта 03. Для чистых контрольных чисел никто другой во время записи не меняет эти палаты. Сгенерированные пароли, параметры БД и окно настройки соединения оставьте за пределами кадра.

| Кадр | Действия | Что показать |
|---|---|---|
| 1. Сотрудники | Администратор открывает «Сотрудники», добавляет тестовую медсестру с адресом `nurse@example.test`. Создайте также врача и заведующую. Двойной щелчок по строке открывает редактирование. На временной учётной записи подтвердите блокировку и проверьте отказ при входе, затем разблокируйте. | Новая строка, роль и статус. Для основного прогона пригодятся три действующие клинические роли. |
| 2. Поступление | Медсестра → Пациенты → Добавить пациентку. Введите **Мария Демонстрационная**, полис **0000000000091025**, 37 недель. Изолятор выключен. Найдите пациентку по последним цифрам полиса. | Сначала карта без размещения. Попытка второй регистрации с тем же полисом выводит предупреждение. |
| 3. Первичное размещение | Врач → Пациенты → выбрать Марию → «В палату» → Приёмное отделение, 101 → «Перевести». | В той же таблице появились отделение и 101. На карте этой палаты свободно **1 из 2**. |
| 4. Между отделениями | Из реестра переведите Марию в Родовое отделение, 201. Двойным щелчком откройте нужное отделение и нажмите палату. | В реестре 201. В 101 свободно **2 из 2**, в 201 **1 из 2**. В 201 видна Мария. Если открыть второй клиент, изменение появится при обновлении или по таймеру. |
| 5. Операционная | Выберите Марию → «В операционную» → 401 → «Перевести». Откройте историю и статистику. | В общем реестре операционный блок и 401. В 201 свободно **2 из 2**, в 401 **0 из 1**. Загрузка операционного блока **50%** при пустой 402. |
| 6. Выписка | Сначала переведите Марию в Послеродовое отделение, 301. Войдите заведующей, найдите Марию, нажмите «Выписать», укажите дату и вымышленные рекомендации. | В 301 снова свободно **3 из 3**. В реестре «Выписана», кнопки перемещения и выписки недоступны. История содержит четыре размещения и выписку. |
| 7. Сверка | В pgAdmin выполните 04_diagnostics.sql на учебной базе. | Восемь строк палат. В каждой mismatch = false. Для случая Марии последнее событие имеет chamber_id IS NULL. |

Если требуется показать изолятор, возьмите Веру Условную из необязательного скрипта 07. В приёмном отделении для неё предлагается 102. В операционном блоке можно выбрать любую свободную операционную. Зарегистрировать другую пациентку, открыть карту, проверить палату или статистику можно без перезапуска программы.
