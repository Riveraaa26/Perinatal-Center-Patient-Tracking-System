# Сравнение поставок и изменения

## Три замечания команды

| Симптом | Что видно в исходниках Александра | Решение и проверка |
|---|---|---|
| Перевод не отражается в БД | Последнее событие выбиралось по date DESC, id DESC, но вставка не указывала date. Результат зависел от DEFAULT, старых NULL и содержимого счётчиков. Дамп для установления точной причины в общей БД отсутствовал. | Из TEAM сохранены явная запись времени, блокировка пациентки и обеих палат в порядке id. В одной транзакции записываются событие, обе загрузки и аудит. Добавлены повторная проверка действующей роли в транзакции и проверка версии размещения в форме. На PostgreSQL выполнены перевод, отказ при гонке и откат при ошибке аудита. |
| Открытый реестр показывает старую палату | Запросы зависели от порядка исторических дат. Перезагрузка страницы могла сбрасывать выбор или поисковую строку. | Реестр, список палаты и история используют один порядок событий. После подтверждения обновляется модель открытого реестра. Через обработчик QML выполнен перевод в операционную, затем в послеродовое отделение. Проверены значения в той же отфильтрованной таблице. |
| Исходная палата остаётся занятой | Условное уменьшение по current_load могло затронуть ноль строк. Старая версия не сверяла результат с фактическим размещением. | Из TEAM сохранён пересчёт по истории после получения блокировок. UPDATE проверяет число изменённых строк, при ошибке операция откатывается. Проверены место исходной палаты, список пациенток получателя, выписка и сверка всех восьми палат отдельным SQL-сеансом. |

ChambersView.qml, DepartamentsView.qml и UserPage.qml совпадают с оригиналом. SQL-диагностика 04 сохранена из TEAM. Удалены из поставки прежняя вспомогательная проверка скобок, каталоги сборки и локальное состояние Qt Creator. Скрипты в tests используются только в отдельной конфигурации. В рабочем приложении тестовый ввод и автоматический вход отсутствуют.

Файлы в Course_Work, Design и исходные файлы Software_Requirements сверены побайтно с архивом Александра. Две копии спецификации, присутствующие в TEAM, идентичны приложенному DOCX.
